核心因果链（教学版）

"矮胖"对 upscale 友好的三条因果：

  1. Upscale 路径有三条：加深 (depth) / 加专家 (expert upcycle) / 加宽 (rare)。起点越浅，加深空间越大—— 从 16 层翻到 32 层 vs 从 27 层翻到 54 层，前者更稳。
  2. Latency 直接收益：推理一个 token 必须顺序走完所有 L 层（不能并行），层少 = latency 减。Option B 比 baseline 减 26%。
  3. Quality 风险：但短模型在 reasoning task 上有 1-2pt 风险（GLM-4.5 选 92 层正是为 reasoning）；不过 Depth Delusion (2026-01) 反向证据指出 7B 上 deep 反而比 wide 差。证据混合，需要 A2 自验。

🛤️ Upscale 路径详解

三条上扩路径（独立或组合）

① Depth Upscaling
方法：SOLAR-DUS / LLaMA Pro / LESA
典型：Mistral 7B 32L → SOLAR 48L
适合：浅起点（headroom 大）
风险：MoE 上 SOLAR 无公开案例
② Expert Upcycling
方法：Sparse Upcycling (Komatsuzaki 2023)
典型：Mistral 7B → Mixtral 8x7B
适合：< 1× 原 dense budget
详见：19_sparse_upcycling.md
③ Width Upscaling
方法：加 hidden + 重 init
典型：罕见
适合：几乎从不用
评论：不推荐
